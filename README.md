# My Pics

A fast photo editor for photographers: auto adjust, crop, watermarks, overlays, green screen removal, and numbered batch export.

## Download

**Windows**

- [Download the installer](../../releases/latest/download/My-Pics-Setup.exe) (recommended)
- [Download the portable version](../../releases/latest/download/My-Pics-Portable.exe) (no install)

**Mac**

- [Apple chip (M1 or newer)](../../releases/latest/download/My-Pics-Mac-arm64.dmg)
- [Intel Mac](../../releases/latest/download/My-Pics-Mac-x64.dmg)

Prefer to browse? See the [latest release](../../releases/latest).

## First time opening it

- **Windows:** if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac:** open the file and drag My Pics into Applications. If macOS blocks it, open System Settings, then Privacy & Security, scroll down and click **Open Anyway**.

My Pics checks for new versions by itself and downloads them in the background.
